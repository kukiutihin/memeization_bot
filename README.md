# Telegram-бот для управления базой изображений

Этот Telegram-бот позволяет:

* Создавать и управлять собственной базой изображений.
* Обращаться к базе с помощью inline-запросов.
* Находить и загружать изображения в общую базу.
* Использовать систему рекомендаций для поиска изображений с похожими тегами, что значительно расширяет возможности поиска.

## Зависимости

* Python 3.10
* python-telegram-bot 20.0
* sqlite3 3.51.0

## Запуск

```bash
python3 src/main.py
```


## Конфигурация

* `token` — токен вашего Telegram-бота.
* `required_match_score` — коэффициент совпадения тегов двух изображений для определения их схожести.
* `recommendations_count` — количество изображений, выводимых в режиме inline.
* `ghosts_count` — количество скрытых тегов, определяемых для каждого тега. Это самые часто используемые вместе с рассматриваемым теги.
